Operating-system packages in the Sangam container images - written offer of source code (decision 118, CR-06, CR-20)

Each Sangam container image is built on a third-party base image (for example Eclipse Temurin on Ubuntu, Debian
distroless, Alpine nginx or Node). That base image contains operating-system packages (dpkg/apk/rpm packages) from
the distribution it is built on. Some of those packages are licensed under the GNU General Public License or the
GNU Lesser General Public License (GPL-2.0, GPL-3.0, LGPL-2.1, LGPL-3.0 and related versions).

- Sangam does not modify those packages. They are shipped as the base-image distribution built them.
- Packages that a Sangam Dockerfile installs on top of the base image are covered the same way. In particular the
  sangam-script-worker image installs the Ubuntu packages libnl-3-200 and libnl-route-3-200 (libnl3, LGPL-2.1),
  unmodified shared libraries used by nsjail; their exact versions are recorded with the image SBOM of each
  release, and their source is at https://launchpad.net/ubuntu/+source/libnl3 for that version.
- The image SBOM published with each release (sbom/<image>_<version>.cdx.json, CycloneDX, generated by syft)
  lists every operating-system package with its name, version, distribution and declared licence.
- The corresponding source code of each package is available from its distribution, for the version listed in
  the image SBOM:
    Debian and distroless (Debian based):  https://sources.debian.org/ and https://snapshot.debian.org/
    Ubuntu:                                https://launchpad.net/ubuntu/+source/<package>
    Alpine:                                https://gitlab.alpinelinux.org/alpine/aports (and the distfiles mirrors)
- On request, for at least three years from the date you received the image, the Sangam project will provide the
  complete corresponding source code of any GPL or LGPL package in that image, for no more than the cost of
  physically performing the distribution. Contact the maintainers listed in the project's NOTICE file, giving the
  image name, version or digest, and the package name and version from the image SBOM.

Packages under the GNU Affero General Public License are not accepted in a Sangam image (licence-policy.json).
This file describes where source code can be obtained. It is not legal advice and makes no statement about
compliance with any licence or law.
