Sangam PDF validator image - third-party components and source locations
(owner decisions 94, 102, 114, 119; RM-26)

The Sangam code in this image (sangam-pdf-validator, sangam-integration, sangam-core) is licensed under the
Apache License 2.0. The jars under /opt/sangam/pdf-validator/lib are shipped unmodified and separately, each under
its own licence. The full component list with exact versions and licences is the image SBOM published with each
release (M-147); this file names the components whose terms ask for a source location.

  Offered under GPL-3.0-or-later OR MPL-2.0. Sangam elects MPL-2.0 (owner decision 94).
  Source: https://github.com/veraPDF (the repositories of these artifacts, tags matching the jar versions) and the
  -sources jars at https://repo1.maven.org/maven2/org/verapdf/
  MPL-2.0 text: https://www.mozilla.org/en-US/MPL/2.0/

Mozilla Rhino 1.7.15.1 (org.mozilla:rhino)
  MPL-2.0. Needed by veraPDF to evaluate its validation-profile rules. This image is the only Sangam distribution that
  contains it (decision 119); the Sangam server never does.
  Source: https://github.com/mozilla/rhino (the release tag of this version) and
  https://repo1.maven.org/maven2/org/mozilla/rhino/1.7.15.1/
