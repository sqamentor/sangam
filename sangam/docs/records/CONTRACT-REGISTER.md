# Contract register

API contract changes that consumers (the UI, IFMS, SDK users) must know about, newest last. The machine contract is
`sangam-rest/api/sangam-api.yaml`, generated by `sangam-rest/api/gen_openapi.py` (never edited by hand); every change
here is additive unless the row says otherwise.
