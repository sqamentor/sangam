# Data Processing Agreement

This agreement is made on {{agreementDate}} between {{fiduciaryName}}, the Data Fiduciary, and {{processorName}}, the Data Processor, for the processing described in Schedule 1. It is entered into under section 8(2) of the Digital Personal Data Protection Act, 2023, which allows a Data Fiduciary to engage a Data Processor only under a valid contract. This text is a template: the parties must have it reviewed by their own legal advisers before signing.

## 1. Subject matter and instructions

1.1 The Data Processor processes personal data only on behalf of the Data Fiduciary, only for the purposes in Schedule 1, and only on the documented instructions of the Data Fiduciary.

1.2 The Data Fiduciary remains responsible for complying with the Act in respect of processing by the Data Processor (section 8(1)).

## 2. Reasonable security safeguards

2.1 The Data Processor takes reasonable security safeguards to prevent a personal data breach (section 8(5)), including at least the measures of rule 6(1) of the Digital Personal Data Protection Rules, 2025:
(a) securing personal data by encryption, obfuscation, masking or virtual tokens;
(b) controlling access to the computer resources it uses for the processing;
(c) giving visibility of access to personal data through logs, monitoring and review, so that unauthorised access can be detected, investigated and remediated;
(d) continuity measures such as data backups;
(e) retaining such logs and personal data for one year for detection, investigation and continuity, unless another law requires otherwise;
(f) the technical and organisational measures needed to make these safeguards effective.

2.2 This clause is the contract provision for security safeguards that rule 6(1)(f) requires between a Data Fiduciary and a Data Processor.

## 3. Personal data breach

3.1 The Data Processor tells the Data Fiduciary of any personal data breach without delay, and in any case within {{breachNoticeHours}} hours of becoming aware of it, with the facts it knows, so that the Data Fiduciary can intimate the Data Protection Board and each affected Data Principal (section 8(6), rule 7).

3.2 Where the breach is also a cyber security incident of a type listed by CERT-In, the Data Processor supports the report to CERT-In within six hours of noticing the incident (CERT-In Directions of 28 April 2022).

3.3 The Data Processor gives the Data Fiduciary the information the Board asks for within 72 hours of the Data Fiduciary becoming aware of the breach (rule 7(2)(b)).

## 4. Withdrawal of consent, erasure and retention

4.1 When the Data Fiduciary tells the Data Processor that a Data Principal has withdrawn consent, or that the specified purpose is no longer served, the Data Processor stops processing and erases the personal data, unless a law requires it to be retained (sections 6(6) and 8(7)).

4.2 The Data Processor retains the personal data, associated traffic data and processing logs for at least one year from the date of processing for the purposes of the Seventh Schedule, and erases them after that period unless a law requires longer retention (rule 8(3)).

4.3 At the end of this agreement the Data Processor returns or erases the personal data, as the Data Fiduciary instructs, and confirms the erasure in writing.

## 5. Rights of Data Principals

5.1 The Data Processor helps the Data Fiduciary to answer requests of Data Principals for access, correction, completion, updating and erasure, and to give the identities of the Data Fiduciaries and Data Processors with whom the data was shared (sections 11 and 12).

## 6. Sub-processors and transfers

6.1 The Data Processor engages another processor only with the prior written consent of the Data Fiduciary and under a written contract with obligations no less protective than these.

6.2 The Data Processor processes and stores the personal data in {{processingLocations}}. It does not transfer personal data outside India to a country restricted by the Central Government under section 16, and makes no other transfer without the prior written consent of the Data Fiduciary.

## 7. Confidentiality and audit

7.1 The Data Processor keeps the personal data confidential and ensures that every person it authorises to process the data is bound by confidentiality. Disclosure of personal information in breach of a lawful contract is an offence under section 72A of the Information Technology Act, 2000.

7.2 The Data Processor makes available to the Data Fiduciary the information needed to show compliance with this agreement, and allows audits by the Data Fiduciary or an auditor it appoints, on {{auditNoticeDays}} days' notice.
