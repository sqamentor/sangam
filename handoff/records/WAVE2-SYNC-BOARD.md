# Wave 2 sync board, shared by all lanes (owner order, 2026-11-12)

The owner wants every lane in sync with the others: no double work, no crossed edits, no wasted effort.
**This board is mandatory for every lane. Read it before you start a piece of work, and before you edit any file another module depends on.**

## Rules
1. **Before you change something other modules use, post an entry here first.** That means a public signature, a constructor, a bean, a table or column, a config key, a REST or AsyncAPI shape, or a file another lane imports.
   - Name the old and new shape, the consumers (found by grep, with file:line), and the lane that owns each consumer.
   - If a consumer is in another lane's file, do not break it silently. Either keep the old signature (an add-only overload) until the owning lane switches, or post a REQUEST to that lane and tell the integrator in your report.
2. **After your change lands, post DONE with the SHA-256 of the changed file.**
3. **Before you build something, search this board, FILE-CLAIMS.md, WAVE2-CARRY and the register.** Someone may already be building it, or may need it. If so, reuse it or coordinate. Never build a second copy (a second formula, helper, pool or table).
4. **When you need something from another lane, post a REQUEST** naming the owner lane. Owners check the board at every step and answer with ACK or DONE.
5. **Your compile gates must be green on the live tree, not on an archive copy.** If another lane's change breaks your gate, post BROKEN with the error line and the owner lane, and keep working on what you can. The integrator chases the owner.
6. Write one line per entry, newest at the bottom, in this format: `UTC time | lane/worker | TYPE (CHANGE/DONE/REQUEST/ACK/BROKEN/INFO) | what | consumers or target lane`.
7. The integrator reads this board after every report and routes anything still open.
