## House rules (binding)

- Unit tests are mandatory for every change. Write them; do NOT run test suites, ITs, Testcontainers or benchmarks. Never weaken or remove an existing assertion.
- Data and generated files change only through their generators. packgen `--check` must pass. profilegen, generate_changelogs and gen_openapi must show no diff on a second run. Never edit an old changeset; add a new one.
- **File ownership:** edit only the files your lane owns (§3 Wave 1).
