## Owner decisions (2026-11-12) that override any backlog text
1. **English only for the initial release (Q-06, register SL-147).** Do not add or translate any UI language content.
   - **New UI strings:** go in `en.json` only. Other locales fall back to English.
   - **What stays:** externalized strings, stable keys, Unicode, and locale-aware formatting. Do not remove `hi.json` or the i18n infrastructure.
   - **Data:** Hindi and other Unicode names, documents and data must be accepted, stored and displayed correctly.
   - **Priority within 0.1.0:** core workflow correctness, real authorization, financial controls, auditability, Oracle/SQL Server compatibility, end-to-end acceptance.
2. **Private ingress (Q-09):** a first-class `ingress.private.enabled` with an internal className, plus schema-validated AWS/Azure/GCP annotation presets. A public className with private=true is refused.
3. **Signing keys (Q-04):** separate Ed25519 keys per purpose (audit checkpoint, package signing) and per environment, referenced through the secret provider. Checkpoints run every hour or every 10,000 entries, configurable. The custodian is named later, so the config carries no real keys.
4. **React UI ADR (Q-17):** record an ADR stating that the React 18 UI replaces the webapps-neo base.
5. The earlier decisions recorded in the register rows and the carry list stand. These include:
   - SL-133 durable pending-audit rows;
   - SL-138 cluster-wide jti;
   - SL-142 park-then-ack for MOVED/PURGED;
   - ConfigConnector `ref`, falling back to operationId;
   - SG-15 evidence first, and one AUDIT_VIEWED per user-visible task.get;
   - receipt format `RCP/{channel}/{date}/{n}`.
