# sangam-rollup (SCALE)

National / cross-cell read model (port 8095, management 8096), own database, counts and identifiers only. Design:
`../SCALE-ARCHITECTURE.md` section 8.

| File | Covers |
|---|---|
| `RollupProjector.java` | Idempotent projection: dedup row + sharded counters for every hierarchy prefix in one transaction (VI.2.3 rule 4); `process.open` gauge; dedup retention |
| `RollupController.java` | `POST /api/v1/ingest` (CloudEvent or array; 422 for a single rejected event = poison), `GET /api/v1/rollup/metrics?node=&from=&to=`, `/series`, `/children`, `/feeds` |
| `RollupConfig.java` | Own Liquibase changelog (`db/changelog/rollup`, five dialects, generated by `../sangam-control-plane/tools/generate_scale_changelogs.py`); tokens CELL (ingest), DASHBOARD (read) |

Gaps: micro-batch pre-aggregation and a state-level roll-up tier (design section 8.4).

Dependencies: Spring Boot 4.1.2 starters (webmvc, jdbc, actuator, security), Liquibase 4.33.0, HikariCP (Apache-2.0);
JDBC drivers as the control plane.
